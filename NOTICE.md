# Notice and credits

Executive Decision Grill (called Decision Grill until 9 November 2026) adapts thinking methods from **Matt Pocock's skills**
(<https://github.com/mattpocock/skills>, commit `4588b32`, reviewed October 2026), which are
published under the MIT licence.

The methods were rewritten in our own words for non-technical executives (CEOs, CFOs, COOs, directors
and managers). Nothing is copied word for
word, apart from a few short phrases that name a method (for example "grill the send, not the
subject"). This project contains no code from that repository and does not install or depend on it.

Several standing rules come from our own earlier product, the Leadership Thinking Partner
(Metamorfeus), which adapted methods from gstack by Garry Tan (MIT licence). Those rules are our
own wording and were tested there first.

| Our mode or rule | Source it adapts |
|---|---|
| Mode 1 · Decision Grill | `skills/productivity/grilling` (called by `grill-me`): the decision tree, asking only what can be answered now, a recommended answer with every question, "facts are the AI's job, decisions are the user's", the finish line and the final confirmation |
| Mode 1, "Sharpen the key words" and "Terms we agreed" | `skills/engineering/domain-modeling` (with `grill-with-docs`): splitting words with two meanings, edge cases, a decision record only for decisions that are hard to reverse |
| Mode 1, "Three options" | `skills/engineering/codebase-design/DESIGN-IT-TWICE.md`: radically different options and an opinionated recommendation |
| Mode 1, "Not yet clear" | `skills/engineering/wayfinder`: the "fog or question?" test |
| Mode 2 · Questionnaire | `skills/productivity/to-questionnaire`: "grill the send, not the subject", the document structure, one idea per question, "why this matters" only where needed |
| Mode 2, Context section | `skills/engineering/triage`: "what we've established so far" and "what we still need from you" |
| Standing rule 8 ("Wait, what?") | `skills/productivity/wait-what` |
| Standing rule 14, the final-output check | `skills/engineering/to-spec`: "you remember making every decision in it; it invented nothing" |
| Standing rules 1–5, 7 and 11–13 | Leadership Thinking Partner standing rules (Metamorfeus), shortened |
| Standing rules 9–10 | The same privacy rules, extended with limits that exist only for the questionnaire (our own wording) |
