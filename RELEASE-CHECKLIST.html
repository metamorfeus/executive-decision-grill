4. Publication steps (each needs the owner's yes)

Run from the product folder in Git Bash. Use the account's usual identity (metamorfeus). Stage named files only; never git add -A in a folder that holds archive/.

Step 1 · Create the local repository and check what it will hold.

cd "/c/OD/OneDrive - ADVANCED HARMONY ASSOCIATION/METAMORFEUS/DECISION-GRILL"
gh auth status
git init -b main
git add .gitignore .gitattributes .nojekyll .github README.md LICENSE NOTICE.md CHANGELOG.md \
        PROJECT-INSTRUCTIONS.md PASTE-INTO-CLAUDE.txt index.html RELEASE-CHECKLIST.html docs tests
git ls-files --eol tests/independent-runs | grep -c 'attr/-text'   # every record file is -text
git ls-files | grep -i -E '^archive/|live-check/|sealed'     # must print nothing
git ls-files | wc -l                                         # expect 915
git cat-file -p :PASTE-INTO-CLAUDE.txt | sha256sum           # must start 9a987f08
git commit -F message.txt                                    # message written to a file first

Step 2 · Create the public repository and push.

gh repo create metamorfeus/executive-decision-grill --public --source . --remote origin --push \
  --description "Free Claude Project instructions for CEOs, CFOs, COOs, directors and managers, built to question a business decision, produce a decision map and draft a questionnaire for whoever holds the missing answers—with nothing to install. Claude recommends; you decide. Adapted from Matt Pocock’s methods. Simulated tests only; live check pending. MIT."

Step 3 · Topics, home page and GitHub Pages.

gh repo edit metamorfeus/executive-decision-grill \
  --homepage "https://metamorfeus.github.io/executive-decision-grill/" \
  --add-topic claude,claude-ai,claude-projects,project-instructions,system-prompt,prompt-engineering \
  --add-topic executive,ceo,cfo,coo,claude-project-instructions,management \
  --add-topic decision-making,decision-support,critical-thinking,questionnaire,grill-me \
  --add-topic business-strategy,generative-ai,no-code
gh api -X POST repos/metamorfeus/executive-decision-grill/pages -f "source[branch]=main" -f "source[path]=/"
gh label create feedback --repo metamorfeus/executive-decision-grill --description "From the feedback form" --color C5DEF5

The topic list has 20 entries. claude-project-instructions reflects the measured phrase “claude project instructions” (260 US searches per month; no Canada row returned in the 14 October 2026 data). The remaining topics describe the product or its audience; no demand is claimed for each tag. grill-me and questionnaire were not measured. Then upload docs/social-preview.png by hand under Settings → General → Social preview; GitHub offers no command for it.

Step 4 · Check it.

gh repo view metamorfeus/executive-decision-grill --json url,visibility,defaultBranchRef,repositoryTopics,homepageUrl
git status -sb                                   # expect: ## main...origin/main
gh api repos/metamorfeus/executive-decision-grill/pages --jq .status   # expect: built (allow a few minutes)
curl -s https://raw.githubusercontent.com/metamorfeus/executive-decision-grill/main/PASTE-INTO-CLAUDE.txt | sha256sum   # 9a987f08...

Then open the home page in a browser, click Copy the instructions, paste into a text editor, and check that it starts with "You are my decision partner" and ends with the last line of the instructions. Open each guide from the home page.

Step 5 · Optional. A GitHub release v1.5 (gh release create v1.5 --title "Executive Decision Grill v1.5" --notes-file notes.md, with the v1.5 and name-change entries of CHANGELOG.md as the notes) gives a fixed download. The Leadership Thinking Partner's README can gain a link back to this repository, as a separate commit there.

5. How to undo

gh auth refresh -h github.com -s delete_repo                  # once: gh needs this right to delete
gh repo delete metamorfeus/executive-decision-grill --yes     # removes the repository and its Pages site
rm -rf .git                                                   # in the product folder; the files stay

Copies already made by others or by search engines while the repository was public cannot be recalled. Smaller steps (take only the home page down, make the repository private, withdraw one version) are in docs/HOW-TO-RELEASE.html, section 5.

6. After publishing

  • Change the status at the top of this page to published, with the date and first commit, and record the owner's words in section 3.
  • Update the repository line in docs/WHAT-WAS-BUILT.html (section 4 and open items).
  • The home page address can serve as the landing page behind the book's short URL. Changing the book is the Bulgarian-edition pipeline's job, not this one.
  • Run the live check (R1) and report its result openly, whatever it is.
  • Click the copy button in Safari or on an iPhone, and in Chrome, and record the result in section 2.
  • For every later version, follow docs/HOW-TO-RELEASE.html.
