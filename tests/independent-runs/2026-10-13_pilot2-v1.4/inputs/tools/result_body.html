6. Disclosures about the test itself

  • The instructions as run had a stray prefix, in all runs of both pilots. I produced the file by cutting at the first place the phrase "You are my decision partner" appears. That phrase also sits inside the setup comment, so the file begins with 211 characters of the comment's tail: You are my decision partner" to the end of this file into the "Set project instructions" box of a Claude Project ... Written by Metamorfeus. -->. The real instructions follow it unchanged. Text pasted into a real Project would not have this prefix. Both preview pages described the start of the text inexactly. I think the fragment is unlikely to explain the failures, because the rules and steps are intact and the behaviour matches what earlier transcripts of the same version showed. But I cannot prove it had no effect, and the readers saw it too. It has to be fixed before any further run.
  • Two conversations stopped early because of my own stop, not because of a usage limit or the assistant. The spend stop at $11 for the four conversations was too tight: they cost $11.43 together.
  • The watch-for lists carry scenario details. Both readers noted this under "Leaks" and guessed that the leader followed a planned script. They did not learn the version or the model.
  • The script's phrase list for second asks again did not point at the readers' one-question failure. That check needs rework.

8. What this shows, and what it does not

  • Shows: on fresh scenarios, version 1.4 repeats the same four kinds of failure that the first pilot found. The method works: independent authors and readers gave consistent, evidence-based results (98 percent agreement), and a rule written first kept the verdict from being argued afterwards.
  • Does not show: anything about the Claude app, connected tools, the long paste, other models or real executives; that the instructions are worse than before; or anything about the sealed half (untouched). AI-written scenarios, AI-written lists and AI readers are a lead, not a release claim.
